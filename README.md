🎮 Simon Says Game

A fun and interactive **Simon Says Game** built using **HTML, CSS, and JavaScript**.  
Test your memory skills by following and repeating the color patterns!

---
🚀 Features

- 🎯 Increasing difficulty with each level
- 🎨 Colorful and responsive UI
- 🔊 Sound effects (if added)
- 🧠 Improves memory and concentration
- 💻 Runs directly in the browser

---
🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---
▶️ How to Play

1. Press any key / Click Start to begin the game.
2. Watch the color sequence carefully.
3. Repeat the same sequence by clicking the buttons.
4. Each round adds a new color.
5. Try to reach the highest level possible!
